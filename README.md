## 🌍 Elementos: Tierra, Fuego y Agua
¡Bienvenido a Elementos! Un juego de consola sencillo pero adictivo desarrollado en Python. Es una variante temática del clásico "Piedra, Papel o Tijera" donde los elementos de la naturaleza se enfrentan en un duelo de lógica.

## 🚀 Cómo jugar
Ejecuta el script de Python.

Ingresa tu nombre de jugador.

Elige uno de los tres elementos cuando se te solicite:

Tierra

Fuego

Agua

Para terminar el juego y ver las estadísticas finales, pulsa la tecla (S).

## ⚔️ Reglas del Juego
El sistema de combate sigue una lógica circular:
Element a Agua 💧 Vence a Fuego (lo apaga)
Fuego 🔥 vence a Tierra (la quema)Tierra 🌿 vence a Agua (la absorbe)
## 🛠️ Requisitos
Python 3.x instalado.

No requiere librerías externas (solo utiliza el módulo nativo random).

## 📁 Estructura del Código
El script incluye:

Validación de entrada: El programa detecta si el texto ingresado es válido o no.

Control de mayúsculas: No importa si escribes en mayúsculas o minúsculas.

Sistema de puntuación: Un contador dinámico de victorias para el jugador, la computadora y empates.
